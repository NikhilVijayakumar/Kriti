# Semantic Rubric: Methodology

## Scoring Criteria

### C1: Design Justification
- **criterion_id**: C1
- **points**: 25
- **mandatory**: true
- **description**: Is each design/heuristic choice justified (why this threshold, why this architecture over an alternative)?
- **pass_condition**: Design decisions include rationale, not just assertions

### C2: Reproducibility
- **criterion_id**: C2
- **points**: 25
- **mandatory**: true
- **description**: Is the methodology described in sufficient detail for another researcher to reproduce the approach?
- **pass_condition**: Algorithm steps clear, parameters specified, tools identified

### C3: Variable Definition
- **criterion_id**: C3
- **points**: 15
- **mandatory**: false
- **description**: Are all variables defined at first use with consistent notation?
- **pass_condition**: Every symbol in equations has a definition, notation consistent

### C4: Diagram Quality
- **criterion_id**: C4
- **points**: 15
- **mandatory**: false
- **description**: Is the block diagram/architecture figure clear, referenced in text, and placed after first reference?
- **pass_condition**: Diagram present, referenced, properly placed

### C5: Novelty Identification
- **criterion_id**: C5
- **points**: 10
- **mandatory**: false
- **description**: If extending an existing technique, is the extension's novelty specifically identified?
- **pass_condition**: Extension clearly differentiated from base technique
