# Formatting Mistakes

> *Source: PCEMS 2026 Template + Conference Guidelines + Sample Paper Analysis*

## Purpose

Formatting mistakes are the most common cause of desk rejection. This document identifies specific formatting errors observed in submitted papers and provides corrections.

## Document Format

### Mistake: Wrong File Format
**Wrong**: Submitting as PDF, LaTeX, or Google Docs
**Correct**: Submit as Microsoft Word (.docx)

**Why**: PCEMS requires Word format for editorial processing. PDF submissions may be desk-rejected.

### Mistake: Multi-Column Layout
**Wrong**: Using two-column format like IEEE or ACM templates
**Correct**: Single-column layout throughout

**Why**: PCEMS template specifies single-column. Multi-column is a different conference format.

### Mistake: Wrong Page Size
**Wrong**: Using A4 when letter size is required (or vice versa)
**Correct**: Verify conference page size requirement

## Font Mistakes

### Mistake: Wrong Font Family
**Wrong**: Times New Roman, Calibri, or Cambria for body text
**Correct**: Arial throughout the entire document

**Verification**: Select all text (Ctrl+A), check font is Arial

### Mistake: Wrong Font Sizes
**Wrong**: Using same size for title, headings, and body
**Correct**:
- Title: 14pt bold
- Author names: 12pt bold
- Affiliations: 11pt
- Heading Level 1: 12pt bold
- Heading Level 2: 12pt
- Heading Level 3: 12pt italic
- Body text: 11pt

### Mistake: Inconsistent Bold/Italic Usage
**Wrong**: Bold for some headings, not others; random italic usage
**Correct**:
- Level 1 headings: bold
- Level 2 headings: plain
- Level 3 headings: italic
- Body text: plain (no bold, no italic except for emphasis)

## Section Numbering

### Mistake: Arabic Numerals Instead of Roman Numerals
**Wrong**: 1. Introduction, 2. Related Work, 3. Methodology
**Correct**: I. INTRODUCTION, II. RELATED WORK, III. METHODOLOGY

**Why**: All 11 accepted sample papers use Roman numeral section numbering.

### Mistake: Inconsistent Section Numbering
**Wrong**: I. Introduction, II. Related work, 3. Methodology
**Correct**: I. INTRODUCTION, II. RELATED WORK, III. METHODOLOGY

## Figure and Table Placement

### Mistake: Figures at End of Paper
**Wrong**: Collecting all figures in a separate section at the end
**Correct**: Place each figure immediately after its first reference in the text

**Why**: All 11 sample papers place figures inline after first reference.

### Mistake: Figures Before First Reference
**Wrong**: Placing a figure before it is mentioned in the text
**Correct**: First reference the figure in text, then place it

### Mistake: Missing Captions
**Wrong**: Figure with no caption, or caption inside the figure
**Correct**: Caption below figure, numbered sequentially (Fig. 1., Fig. 2.)

### Mistake: Table Captions Below Table
**Wrong**: Placing table caption below the table
**Correct**: Table caption above the table

## Citation Format

### Mistake: Author-Year Citations
**Wrong**: (Smith et al., 2023) or (John 2023)
**Correct**: [1], [2], [3]

**Why**: All sample papers use IEEE numbered citation style despite the template mentioning APA.

### Mistake: Inconsistent Citation Numbers
**Wrong**: [1] appears twice for different references, or [5] skips to [7]
**Correct**: Sequential, unique numbers for each reference

## Spacing and Margins

### Mistake: Inconsistent Line Spacing
**Wrong**: Single spacing in some sections, double in others
**Correct**: Consistent line spacing throughout (verify conference requirement)

### Mistake: Wrong Margins
**Wrong**: Using default margins that don't match template
**Correct**: Verify and apply conference margin requirements

## Header and Footer

### Mistake: Missing Running Header
**Wrong**: No header or footer with paper title or page numbers
**Correct**: Include page numbers; include paper title in header if required

## Quick Verification Commands

Before submission, verify:
1. Open document, Ctrl+A to select all, check font is Arial
2. Check title is 14pt bold
3. Check body text is 11pt
4. Check section numbers are Roman numerals
5. Check every figure is after its first text reference
6. Check citation numbers are sequential
7. Check page count is within limit
