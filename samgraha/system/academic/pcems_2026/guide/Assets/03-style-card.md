# Style Card

> *Source: PCEMS 2026 Template + Conference Guidelines + Sample Paper Analysis*

## Purpose

One-page style reference for PCEMS 2026 manuscripts. Print this document and keep it visible while writing.

## Document Format

```
Format:       Microsoft Word (.docx)
Layout:       Single column
Font:         Arial (all elements)
Page size:    As per conference requirement
```

## Font Sizes

```
Title:        14pt, bold, centered
Authors:      12pt, bold, centered
Affiliations: 11pt, centered
Heading 1:    12pt, bold, left-aligned
Heading 2:    12pt, left-aligned
Heading 3:    12pt, italic, left-aligned
Body:         11pt, left-aligned
Keywords:     12pt, bold
References:   8pt
```

## Section Numbering

```
I.    INTRODUCTION
II.   RELATED WORK
III.  METHODOLOGY
IV.   RESULTS AND DISCUSSION
V.    CONCLUSION
VI.   REFERENCES
```

Roman numerals. All caps for section titles.

## Citation Style

```
In-text:      [1], [2], [3]
Reference:    Numbered, sequential
Style:        IEEE numbered format
```

## Figure Rules

```
Numbering:    Fig. 1., Fig. 2., Fig. 3.
Placement:    Immediately after first reference
Caption:      Below figure
Resolution:   Minimum 300 DPI
Grayscale:    Must be readable in grayscale
```

## Table Rules

```
Numbering:    TABLE I, TABLE II, TABLE III
Placement:    Inline after first reference
Caption:      Above table
Headers:      Clear and descriptive
```

## Abstract Rules

```
Length:       150-250 words
Structure:    Problem, method, results, contribution
Citations:    None in abstract
Keywords:     at least 4-5, after abstract
```

## Writing Rules

```
Voice:        Active preferred
Sentences:    15-25 words target, 40 max
Paragraphs:   4-8 sentences target, 12 max
Abbreviations: Define at first use
Terminology:  Consistent throughout
```

## Red Flags (Check Before Submission)

```
[ ] No AI-generated language (delve, tapestry, landscape)
[ ] No informal language (a lot, basically, very)
[ ] No passive voice overuse
[ ] All figures after first reference
[ ] All citations sequential
[ ] All abbreviations defined
[ ] Arial font throughout
[ ] Correct font sizes
[ ] Roman numeral sections
[ ] IEEE numbered citations
```

## Reference Count

```
Target:       15-30 references
Recent:       At least 5 from last 3 years
Foundational: At least 2 seminal works
```

## Word Count Guidelines

```
Total:        3,200-4,000 words (target)
Abstract:     150-250 words
Introduction: 500-600 words
Lit Review:   500-600 words
Methodology:  800-1,000 words
Findings:     800-1,000 words
Conclusion:   200-300 words
```

## Quick Compliance Check

Before submission, verify:
1. File is .docx
2. Font is Arial throughout
3. Title is 14pt bold
4. Body is 11pt
5. Sections are Roman numerals
6. Citations are [1], [2] format
7. Figures are inline after first reference
8. Abstract is 150-250 words
9. References are 15-30
10. No AI-generated language patterns
