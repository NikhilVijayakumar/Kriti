# Font Reference

> *Source: PCEMS 2026 Template*

## Purpose

Quick reference for all font specifications in PCEMS 2026 manuscripts. Use this document to verify formatting compliance.

## Font Family

**Required**: Arial (all elements)

No other font families are permitted. This includes body text, headings, captions, headers, footers, tables, and figure labels.

## Font Size and Style Specifications

| Element | Size | Style | Notes |
|---------|------|-------|-------|
| Paper Title | 14pt | Bold | Centered |
| Author Names | 12pt | Bold | Centered |
| Affiliations | 11pt | Normal | Centered |
| Heading Level 1 | 12pt | Bold | Left-aligned |
| Heading Level 2 | 12pt | Normal | Left-aligned |
| Heading Level 3 | 12pt | Italic | Left-aligned |
| Body Text | 11pt | Normal | Left-aligned |
| Abstract | 11pt | Normal | Indented or as specified |
| Keywords | 12pt | Bold | After abstract |
| References | 8pt | Normal | As specified by template |
| Headers | As per template | As per template | Consistent throughout |
| Footers | As per template | As per template | Page numbers |

## Verification Steps

1. Select all text (Ctrl+A)
2. Verify font is Arial
3. Check title is 14pt bold
4. Check body text is 11pt
5. Check headings follow the pattern above
6. Check keywords are 12pt bold

## Common Font Mistakes

| Wrong | Correct |
|-------|---------|
| Times New Roman for body | Arial 11pt |
| 12pt for body text | 11pt for body text |
| Bold for all headings | Only Level 1 bold |
| 11pt for keywords | 12pt bold for keywords |
| Mixed fonts in document | Arial throughout |

## Quick Check

Run this verification on the final document:
- Title: 14pt bold Arial
- Authors: 12pt bold Arial
- Affiliations: 11pt Arial
- Keywords: 12pt bold Arial
- H1: 12pt bold Arial
- H2: 12pt Arial
- H3: 12pt italic Arial
- Body: 11pt Arial
- References: 8pt Arial
