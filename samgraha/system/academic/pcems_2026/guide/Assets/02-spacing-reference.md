# Spacing Reference

> *Source: PCEMS 2026 Template*

## Purpose

Quick reference for all spacing specifications in PCEMS 2026 manuscripts. Consistent spacing improves readability and demonstrates attention to detail.

## Line Spacing

| Element | Spacing | Notes |
|---------|---------|-------|
| Body text | As per template | Verify conference requirement |
| Headings | As per template | Usually single or 1.15 |
| References | As per template | Usually single |
| Captions | As per template | Usually single |
| Lists | As per template | Usually single |

## Paragraph Spacing

| After headings | As per template | As per template | Before next paragraph |
| Before headings | As per template | As per template | After previous paragraph |
| Between figures | As per template | As per template | Consistent |

## Spacing Between Elements

### After Title
- Space before author names (verify template)
- Space between author and affiliation (verify template)

### After Abstract
- Space before keywords (verify template)
- Space after keywords before body (verify template)

### Between Sections
- Consistent spacing between all sections
- No extra blank lines
- No missing blank lines

### Around Figures and Tables
- Space before figure/table (after text)
- Space after figure/table (before text)
- Space between figure and its caption (minimal)
- Space between table and its caption (minimal)

## Table Spacing

| Element | Spacing | Notes |
|---------|---------|-------|
| Table header row | As per template | Often bold |
| Table body rows | As per template | Consistent |
| Column separation | As per template | Readable |
| Table caption | Above table | As per template |

## Common Spacing Mistakes

| Wrong | Correct |
|-------|---------|
| Double spacing for body | As per template (usually single) |
| No space between sections | Consistent space between sections |
| Extra blank lines | Remove extra blank lines |
| Inconsistent paragraph spacing | Uniform spacing throughout |
| No space after headings | Space after headings as per template |

## Verification Steps

1. Check all margins match template
2. Check line spacing is consistent
3. Check paragraph spacing is consistent
4. Check spacing around figures/tables
5. Check no extra blank lines
6. Check spacing between sections
