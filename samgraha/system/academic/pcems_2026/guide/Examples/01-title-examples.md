# Title Examples

> *Source: PCEMS 2026 Sample Papers + Template Analysis*

## Purpose

The title is the first element reviewers read and the primary factor in search discoverability. This document provides annotated examples from accepted PCEMS 2026 papers, analyzing what works and why.

## Title Patterns Observed in Sample Papers

### Pattern 1: Method + Application Domain

**Examples from sample papers**:
- "Credit Card Fraud Detection Using Machine Learning Techniques"
- "Hybrid Feature Selection and Optimized Deep CNN for Heart Disease Prediction"
- "Early Leaf Diseases Prediction in Paddy Crop Using Deep Learning Model"

**Structure**: [What was built/studied] + [Using what approach] + [For what application]

**When to use**: When the contribution is a new application of existing techniques.

### Pattern 2: Investigation + Physical Phenomenon

**Examples from sample papers**:
- "Investigation of the Direct Source to Drain Tunneling in 5 nm Nanotube Junctionless Field Effect Transistor"
- "Suppression of False-terms in Wigner-Ville Distribution using Time and Frequency Windowing"

**Structure**: [Action verb] + [What is being studied] + [Specific conditions]

**When to use**: When the contribution is analytical or experimental investigation of a phenomenon.

### Pattern 3: System + Capability

**Examples from sample papers**:
- "Iot Based Smart Food Grain Warehouse"
- "Multilingual Indian Language Neural Machine Translation System Using mT5 Transformer"

**Structure**: [System type] + [What it does] + [Technology used]

**When to use**: When the contribution is a complete system or prototype.

### Pattern 4: Comparative Study + Methods

**Examples from sample papers**:
- "Comparative Study of Data Driven Methods for State of Charge Estimation of Li-ion Battery"
- "Commercial Clustering of Indian Bamboo Species Using Machine Learning Techniques"

**Structure**: [Study type] + [What is being compared] + [Domain]

**When to use**: When the contribution is a systematic comparison of approaches.

## Title Writing Rules

### Length
- Target: 10-15 words
- Maximum: 20 words
- Avoid abbreviations in titles (spell out unless universally known)

### Capitalization
- Capitalize first word and all major words
- Do not capitalize articles (a, an, the), prepositions (of, in, for), or conjunctions (and, but, or) unless they start the title

### Specificity
- Include the specific domain or application
- Include the technique or approach when relevant
- Avoid vague terms ("novel," "efficient," "advanced") unless justified

## Anti-Patterns

| Weak Title | Problem | Stronger Alternative |
|-----------|---------|---------------------|
| "A Novel Machine Learning Approach" | Too vague, no domain | "Random Forest Classification for Credit Card Fraud Detection" |
| "An Efficient Algorithm for Data Processing" | No specificity | "Parallel Merge-Sort for Real-Time Sensor Data Streams" |
| "Study of IoT Systems" | No contribution indicated | "Low-Power IoT Gateway Design for Agricultural Sensor Networks" |
| "Improvement of Accuracy in Deep Learning" | No domain, no method | "Data Augmentation for Improved Chest X-Ray Classification" |

## Keywords

Keywords appear immediately after the abstract. They aid search discoverability.

### Keyword Selection Rules
- At least 4-5 keywords
- Include the domain (e.g., fraud detection, grain storage)
- Include the method category (e.g., machine learning, IoT, deep learning)
- Include specific techniques when relevant (e.g., random forest, LSTM, Arduino)
- Avoid single-word keywords unless universally recognized
