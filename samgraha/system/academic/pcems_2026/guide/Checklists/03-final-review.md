# Final Review Checklist

> *Source: PCEMS 2026 Template + Conference Guidelines*

## Purpose

This checklist is for the final review before submission. It catches issues that previous reviews may have missed. Complete it after all revisions are done.

## Document-Level Checks

- [ ] File opens correctly in Microsoft Word
- [ ] No tracked changes or comments visible
- [ ] No hidden text or formatting
- [ ] No placeholder text anywhere (TODO, XXX, [insert], TBD)
- [ ] Spell check completed (no red underlines)
- [ ] Grammar check completed
- [ ] Page count within conference limit

## Title and Metadata

- [ ] Title is accurate and reflects the final content
- [ ] All author names correct and consistently formatted
- [ ] All affiliations correct
- [ ] All email addresses valid
- [ ] ORCID iDs included and correct
- [ ] Keywords are current and relevant

## Abstract Accuracy

- [ ] Abstract reflects the final paper content
- [ ] Problem statement is clear
- [ ] Method summary is accurate
- [ ] Results in abstract match results in paper
- [ ] Word count within 150-250 words
- [ ] No citations in abstract
- [ ] No abbreviations in abstract (or defined if essential)

## Figure and Table Audit

For every figure:
- [ ] Numbered sequentially (Fig. 1., Fig. 2.)
- [ ] Caption present and accurate
- [ ] Referenced in text before first appearance
- [ ] Placed immediately after first reference
- [ ] Legible at print size
- [ ] All labels readable
- [ ] Units included on axes
- [ ] Legible in grayscale

For every table:
- [ ] Numbered sequentially (TABLE I, TABLE II)
- [ ] Caption present and accurate
- [ ] Referenced in text before first appearance
- [ ] Headers are descriptive
- [ ] All entries are complete (no blank cells)
- [ ] Units consistent within columns
- [ ] Alignment consistent

## Citation Audit

- [ ] Citation numbers are sequential (no gaps)
- [ ] Citation numbers are consistent (same number for same reference)
- [ ] Every [n] in text has a corresponding reference [n]
- [ ] Every reference [n] appears at least once in text
- [ ] No citation overlaps with figure/table numbers
- [ ] Reference list formatting is consistent

## Section Content Audit

For each section, verify:
- [ ] Section exists and is properly numbered
- [ ] Content matches the section heading
- [ ] No information duplicated from other sections
- [ ] Transitions connect to adjacent sections
- [ ] No orphaned sentences or paragraphs

## Formatting Compliance (Final Pass)

- [ ] Single-column layout
- [ ] Arial font throughout
- [ ] Correct font sizes for each element
- [ ] Correct bold/italic usage for headings
- [ ] Consistent spacing throughout
- [ ] No extra blank lines between sections
- [ ] Roman numeral section numbering

## Technical Accuracy

- [ ] All numbers verified (check calculations)
- [ ] All units consistent and correct
- [ ] All equations properly formatted
- [ ] All variable names consistent
- [ ] All technical claims supported by results
- [ ] No contradictions between sections

## Co-Author Verification

- [ ] All co-authors have reviewed the final version
- [ ] All co-authors have approved the submission
- [ ] Corresponding author designated
- [ ] Author order agreed upon

## Submission Package

- [ ] Manuscript file ready (.docx)
- [ ] Supplementary materials prepared (if any)
- [ ] Cover letter drafted (if required)
- [ ] Copyright form ready (if required)
- [ ] Registration information prepared
- [ ] Presentation file prepared (if presenting)
