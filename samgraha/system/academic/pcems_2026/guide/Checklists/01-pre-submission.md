# Pre-Submission Checklist

> *Source: PCEMS 2026 Template + Conference Guidelines + Sample Paper Analysis*

## Purpose

Complete this checklist before submitting your manuscript. Every item must be verified. A single unchecked item can cause desk rejection.

## Formatting Compliance

- [ ] Document is a Microsoft Word file (.docx)
- [ ] Single-column layout
- [ ] Font: Arial throughout
- [ ] Title: 14pt, bold
- [ ] Author names: 12pt, bold
- [ ] Affiliations: 11pt
- [ ] Heading Level 1: 12pt, bold
- [ ] Heading Level 2: 12pt
- [ ] Heading Level 3: 12pt, italic
- [ ] Body text: 11pt
- [ ] Section numbering: Roman numerals (I., II., III.)

## Content Structure

- [ ] Title is 10-15 words, descriptive, no abbreviations
- [ ] Author names with affiliations and email addresses
- [ ] ORCID iD included (if available)
- [ ] Abstract: 150-250 words
- [ ] Keywords: at least 4-5 keywords after abstract
- [ ] Introduction states problem, gap, and contribution
- [ ] Related work covers key prior approaches
- [ ] Methodology is detailed enough for replication
- [ ] Results include quantitative comparison with baselines
- [ ] Conclusion summarizes without introducing new information
- [ ] References: 15-30 entries

## Figures and Tables

- [ ] Every figure referenced in text before it appears
- [ ] Every figure placed immediately after first reference
- [ ] Every figure has a caption (below figure, Arial)
- [ ] Figure numbers sequential (Fig. 1., Fig. 2.)
- [ ] All axes labeled with units
- [ ] Figures legible in grayscale
- [ ] Resolution: minimum 300 DPI
- [ ] Every table has a caption (above table)
- [ ] Table numbers sequential (TABLE I, TABLE II)
- [ ] Table headers are clear and descriptive
- [ ] No figures or tables at end of paper

## Citations and References

- [ ] Citation style: IEEE numbered ([1], [2])
- [ ] All in-text citations have reference list entries
- [ ] All reference list entries cited in text
- [ ] Citation numbers sequential and consistent
- [ ] No broken citation numbers
- [ ] References complete (author, title, venue, year)
- [ ] At least 5 references from last 3 years
- [ ] No references older than 20 years without justification

## Language and Writing

- [ ] No informal language (a lot, basically, very good)
- [ ] No AI-generated patterns (delve, tapestry, landscape, paramount)
- [ ] Active voice preferred
- [ ] Sentences under 40 words
- [ ] Paragraphs under 12 sentences
- [ ] All abbreviations defined at first use
- [ ] Consistent terminology throughout
- [ ] Technical terms used precisely

## Technical Content

- [ ] Contribution clearly stated in abstract and introduction
- [ ] Every claim supported by evidence
- [ ] Methodology described in sufficient detail
- [ ] Results include quantitative metrics
- [ ] Comparison with existing methods included
- [ ] Limitations acknowledged
- [ ] Future work connected to limitations

## Final Checks

- [ ] Page count within limit
- [ ] File size reasonable (< 10MB)
- [ ] No track changes or comments visible
- [ ] No placeholder text (TODO, XXX, [insert here])
- [ ] Spell check completed
- [ ] All co-authors have reviewed and approved
