# References Writing Guide

> *Source: PCEMS 2026 Template + Conference Guidelines/05-references.md + Documentation-Standards/06-references-standards.md*

## Purpose

The References section provides complete bibliographic information for every source cited in the paper. It enables readers to locate and verify the cited work.

## Citation Style

PCEMS 2026 specifies **APA referencing style**. However, analysis of accepted sample papers shows that most use **IEEE numbered style** ([1], [2], [3]...). Authors should follow the style specified by their institution or the conference's final guidelines.

### APA Style (as specified in template)

In-text citation: (Author, Year)
Reference list: Alphabetical by first author

```
Smith, J. A., & Jones, M. B. (2023). Title of the article. 
    Journal Name, 15(3), 123-145. https://doi.org/10.xxxx
```

### IEEE Style (as used in sample papers)

In-text citation: [1], [2], [3]
Reference list: Numbered in order of appearance

```
[1] J. A. Smith and M. B. Jones, "Title of the article," 
    Journal Name, vol. 15, no. 3, pp. 123-145, 2023.
```

**Note**: Verify which style is required before finalizing your reference list.

## Requirements

### Font

- **Reference entries**: Arial, 8pt
- **Section heading**: Heading 1 (Arial, 12pt, Bold)

### Formatting Rules

1. **Complete bibliographic information**: Author names, title, journal/conference name, volume, number, pages, year
2. **Consistent formatting**: All entries must follow the same style
3. **100% citation-list match**: Every in-text citation must appear in the reference list, and every reference must be cited in the text
4. **No predatory sources**: Use legitimate journals, conferences, and publishers

## Reference Entry Format (APA)

### Journal Article

```
Author, A. A., Author, B. B., & Author, C. C. (Year). Title of article. 
    Title of Periodical, volume(number), page-page. https://doi.org/xxxx
```

### Conference Paper

```
Author, A. A., & Author, B. B. (Year). Title of paper. In Proceedings of 
    the Conference Name (pp. page-page). Publisher. https://doi.org/xxxx
```

### Book

```
Author, A. A. (Year). Title of work: Capital letter also for subtitle. 
    Publisher.
```

### Website

```
Author, A. A. (Year, Month Day). Title of page. Site Name. URL
```

## Reference Entry Format (IEEE)

### Journal Article

```
[1] A. A. Author, B. B. Author, and C. C. Author, "Title of article," 
    Title of Periodical, vol. X, no. X, pp. XXX-XXX, Month Year.
```

### Conference Paper

```
[1] A. A. Author and B. B. Author, "Title of paper," in Proc. Conference 
    Name, City, Country, Year, pp. XXX-XXX.
```

### Book

```
[1] A. A. Author, Title of Book. City, Country: Publisher, Year.
```

## Reference Count

Based on sample paper analysis:

| Metric | Range | Target |
|--------|-------|--------|
| Reference count | 10-20 | 12-15 |
| Recent references (last 5 years) | 50-80% | 60-70% |
| Journal/conference mix | Varies | Balanced |

## Writing Strategy

### Do

- Include all cited works (100% match)
- Use recent references (last 5 years preferred)
- Include a mix of journal and conference papers
- Verify every reference against the in-text citation
- Use consistent formatting throughout
- Include DOI when available

### Do Not

- Cite references not mentioned in the text
- Include references not read by the authors
- Use only one type of source (all journals or all conferences)
- Use inconsistent formatting between entries
- Exceed 20 references (unless the topic requires more)

## Revision Checklist

- [ ] Every in-text citation appears in the reference list
- [ ] Every reference is cited at least once in the text
- [ ] All entries follow the same citation style
- [ ] Font is Arial, 8pt for all reference entries
- [ ] Complete bibliographic information is provided for each entry
- [ ] References are formatted consistently
- [ ] Recent references (last 5 years) constitute at least 50% of the list
- [ ] No predatory or unreliable sources are included
- [ ] DOI is included where available
- [ ] Reference count is appropriate for the paper's scope
