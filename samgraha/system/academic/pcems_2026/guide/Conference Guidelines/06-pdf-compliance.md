# PDF Compliance

Before submission, verify the generated PDF satisfies all technical requirements.

## Fonts

- All fonts must be embedded.
- Only scalable fonts should be used.

---

## Images

Images must

- Not contain transparent pixels.
- Not contain alpha channels.

---

## Security

The PDF must

- Have no document protection.
- Have no document security enabled.
- Allow normal viewing and printing.

---

## PDF Generation

Use a reliable PDF generation tool that preserves

- Embedded fonts
- Image quality
- Layout consistency
