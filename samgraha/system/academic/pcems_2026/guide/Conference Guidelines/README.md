# PCEMS 2026 Manuscript Preparation Guide

This documentation summarizes the official manuscript preparation requirements
for PCEMS 2026 into a structured engineering-style documentation set.

The objective is to provide a single reference that authors can follow while
writing their paper, formatting the manuscript, generating the PDF, and
preparing the final camera-ready version.

## Documents

1. Submission Requirements
2. Manuscript Structure
3. Formatting Guidelines
4. Figures and Tables
5. References
6. PDF Compliance
7. Submission Checklist


Following all documents ensures that the manuscript satisfies both
conference formatting requirements and publication requirements.
